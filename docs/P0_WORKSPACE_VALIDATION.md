# v0.24.9：赛事隔离与旧录像恢复

2026-10-13 完成现场对数规划的第一步。

旧混合目录根据录像所属赛事及已有人工确认恢复本场赛事和赛段；证据不足以唯一确定时，名单和胶卷等待“选择赛事”。前台胶卷与后台录像目录使用统一范围，不随选中的运动员改变。新消息先进入收件箱，其他赛事或赛段不进入当前名单；历史查看及赛事选择可在重启后恢复。

恢复的赛事信息及手动选择保存为独立本地状态，不创建伪造的 CycleRace 元信息修订，不删除混入的其他赛事原始记录。首人校时的实际生效偏移显示在运动员信息栏，“基础校时”控件用于尚未校准的录像。

## 打开方式

本机桌面快捷方式：`FinishReview-v0.24.9.lnk`。

程序目录：`D:\orca\FinishReview\artifacts\release-0.24.9\FinishReviewConsole`。

压缩包：`D:\orca\FinishReview\artifacts\release-0.24.9\FinishReview-v0.24.9.zip`。复制到其他电脑时解压整个目录，保留 `_internal`，从目录内打开 `FinishReviewConsole.exe`。

新版本沿用现有设备配置和保存根目录。打开定边旧目录后应看到历史复核、本场 302 条记录、295 条人工已确认及可浏览的时间胶卷。“选择赛事”可查看同一目录内的其他赛事。

现场开始新赛事时，在“设置”中通过“返回当前赛事”进入 CycleRace 当前赛事；该入口需要收到当前赛事信息。历史查看期间新消息保存在后台收件箱，当前历史名单不会被替换。
