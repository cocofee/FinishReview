# 离线问题清单：实现与验收

2026-10-14。当前实现是机位 1 的离线核对流程，尚未完成整个实施方案。

## 操作

1. 选择赛事、赛段，等待录像归档及索引就绪。
2. 点击主界面“问题清单”，在录像预览上点击终点线两个端点。
3. 多圈数据指定最后一圈。不同组末圈不同的赛事暂需分组核对。
4. 可选配置 YOLOX-S 640 或 YOLOX-nano 416 的 COCO ONNX 模型。不配置或模型失败时保留全部候选。
5. 启动分析；可以停止，关闭窗口也会停止进程。分析不写原录像或芯片日志。
6. 选择问题，查看卡片并打开原帧；核对后填写原因，保存处理。
7. 导出建议补录、建议删除、建议改号改圈三张 UTF-8 BOM CSV，交由 CycleRace 确认。

## 已实现

- 自动校时支持 ±90 秒粗偏移及线性漂移；至少五个孤立锚点、跨度至少一分钟、残差中位数不超过 50 ms。
- 按时间顺序一对一匹配，普通窗口 ±700 ms；芯片与视频均为孤立到达时扩大至 ±1500 ms。
- 与人工锚点相差超过 300 ms 时明确提示，并禁止自动通过及建议补录；人工校时不被覆盖。
- 顺序解码，用实际 PTS 和帧序号定位，不用文件头 FPS 推算证据。采样块保存为 NPZ，卡片为 JPEG。
- CPU 单进程、OpenCV 单线程、解码最多两线程；Windows 进程低于正常优先级。无模型时也可运行。
- 重复/测试芯片、未匹配芯片和视频、录像缺口、遮挡及集团生成待核对项。
- 至少四个相邻芯片组成的集团，以及存在配对歧义的小集团，需要人工核对。紧邻配对的额外候选不会静默丢弃。
- 自动通过与人工确认分别保存；处理日志绑定赛事、赛段、证据、芯片修订和校时版本。
- 文件签名、终点线、录像索引、芯片或人工校时变化会阻止旧报告处理与导出。
- 本地删除标记绑定修订与身份，并保存原因；上游修订重新进入队列。
- Windows 中文用户目录下 Qt 插件路径异常时，从实际 PyQt5 安装目录补充搜索路径。

采样检测的是终点线附近的活动，无法保证都是有效骑手或前轮压线。
集团、严重遮挡、特殊机位与缺失录像仍需人工判断，禁止把这版当作全自动成绩系统。
