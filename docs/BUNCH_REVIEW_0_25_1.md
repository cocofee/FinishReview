# 0.25.1：集团核对操作窗口

定边演练中，原集团条目只有一张卡片、前后约一秒的小胶片，以及“已核对 / 认号补录”。
这不足以查看整团，也不能分别保存多个漏读者的证据和建议时间。

现在选择集团或拥挤时段后，可从清单上方打开独立核对窗口，或双击该条目打开：

- 整团过线图和芯片刻度，可点击定位；缺少缓存处保留灰色，不推断无人过线。
- 大幅原画面、逐帧前后、滚轮放大、拖动与前轮点击计数；每帧显示附近 ±200 ms 的芯片。
- 每条计数可记号码，号码优先对应同号芯片，其余时间顺序仅供参考；密集处不能用时间认人。
- 原帧时间来自实际解码 PTS，可跨分段录像；独立低优先级工作线程只开一个解码器、两个解码线程，
  缓存限制为约 32 MB 的 JPEG 帧。后台分析运行时须先停止，再打开核对窗口。
- 各机位草稿、计数、号码和累计用时写入独立的 `finish_problems/bunch_reviews.jsonl`。
  返回时保留修改，重新打开可继续，已有 `problem_resolutions.jsonl` 保留。
- 未对应芯片、无法认号、缺少前后插值参考时，继续保留待处理；确认完成后才导出逐人的补录建议。
  同一团可有多个补录者，每人有独立证据帧、校时版本和前后过线插值估算时间。
- 芯片记录、校时或证据变化后，旧结果不继续导出；正式成绩仍由 CycleRace 处理。

前轮与刻度的偏差优先由至少三位独立过线者估计。支持人工参考值，默认 0 ms；
后方机位原型的 120 ms 不直接套到其他机位。
