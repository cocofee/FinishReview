## 每条的处理步骤

1. 在清单里点一条：右边显示卡片（压线时刻）和小胶片（前后各约 1 秒，每 0.25 秒一张）。
2. 需要看清号码时点“跳到原帧”：主画面定位到原录像的这一帧，用原来的逐帧、放大、标线功能核对。
3. 点处理按钮。需要号码的（认号补录、删除多余芯片、建议改号改圈）先在号码框里填号码；原因框可以写说明。
4. 如果同一帧已经确认过别的号码，系统会先提示，确认后才记录（防止定边 029 / 051 那样确认错人）。
5. 处理过的条目从待处理里移走，可以勾“显示已处理和已排除”后找到它，点“重新处理”。
6. 全部处理完后点“导出清单”，会在 `ws_dingbian\finish_problems\exports\` 生成三个文件：
   - `补录清单.csv`：号码、芯片域时间、证据帧、机位、校时版本、说明；
   - `建议删除清单.csv`；
   - `建议改号改圈清单.csv`。

   这三个文件只是给 CycleRace 的建议，FinishReview 不会改正式成绩。CycleRace 改完后，FinishReview 收到修订就会关闭对应条目。
