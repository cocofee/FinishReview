# 0.25.2：集团核对中的非选手排除

## 操作

1. 在集团逐帧核对中点出画面里的人员，在右侧选择对应记录；双击记录可回看其原帧。
2. 查看前后帧，确认是行人、工作人员或其他无关人员后，选择原因，点击 **确认非选手并排除**。
3. 已排除记录显示为灰色，保留原帧、位置、原填号码及排除原因。发现误判时，选择记录并点 **恢复为选手计数**。
4. 保存进度后，再次打开可继续核对；整团看完并满足原有核对条件后，才能确认完成。

看不清号码不能作为非选手排除的依据。本版是人工确认操作，不自动判断行人身份。

## 计算与保存

- 已排除人员不计入选手人数，不参与同号配对、顺序配对、独立过线者偏差估计、补录插值或补录导出。
- 原始记录序号保持不变，后面的选手仍使用各自的证据帧。选手人数和排除人数分别显示。
- 排除记录不会作废任何芯片。排除后仍有芯片无人对应时，本团继续待处理，不能用排除掩盖漏数。
- `finish_problems/bunch_reviews.jsonl` 继续使用追加记录保存。可选字段 `exclusion_reason` 非空表示已排除，旧版草稿没有此字段，仍按选手计数处理。恢复及再次保存也会保留此前已保存的排除历史。
- 导出时根据当前草稿记录重新计算并验证完成条件，缓存中的旧补录建议不能将已排除者带回补录清单。
- 不修改原录像、原始芯片记录或 CycleRace 成绩。
